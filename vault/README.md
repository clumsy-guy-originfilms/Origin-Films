# Origin Films knowledge vault

Plain markdown that opens in Obsidian (open this `vault` folder as a vault). It holds what Origin knows; Notion holds what is happening now.

Rules
- No secrets: no API keys, passwords or banking details.
- No contracts, personal contact details or NDA material. Those stay in Notion.
- Agents never edit this folder directly. Changes arrive as pull requests for Danny to approve.

| Folder | Holds |
|---|---|
| Company | Philosophy, brand voice and guidelines |
| Sales | ICPs, offers, pricing principles |
| Templates | Email templates and lawyer-approved legal templates |
| Operations | SOPs, crew and production checklists |
| Agents | One folder per agent: its instructions |
| Lessons | One short lesson per closed deal or delivered project |
| Clients | Non-sensitive guidelines per client |
